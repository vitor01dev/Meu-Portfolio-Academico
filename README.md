# Portfólio Acadêmico, Vitor Vieira

Bem-vindo ao meu portfólio acadêmico.

Este repositório reúne atividades, projetos, documentações e evidências desenvolvidas durante o curso de **Análise e Desenvolvimento de Sistemas**, na **Faculdade Senac Pernambuco**, referentes ao **5º período, semestre 2026.2**.

O objetivo deste portfólio é reunir as principais atividades acadêmicas desenvolvidas ao longo do período, demonstrar competências técnicas e profissionais adquiridas durante o curso e apresentar projetos aplicados, com destaque para o Projeto Integrador **ConectaStart**.

A organização deste repositório utiliza conceitos de **Arquitetura da Informação**, com foco em classificação, taxonomia, metadados, navegação, encontrabilidade e relações entre conteúdos.

## Projeto Integrador

### ConectaStart

O **ConectaStart** é um projeto voltado ao apoio de startups emergentes, oferecendo orientação e estrutura para auxiliar essas organizações no desenvolvimento de maior credibilidade junto a parceiros, mentores, investidores e demais agentes do ecossistema de inovação.

O projeto busca organizar informações, oportunidades e conexões relevantes para startups em diferentes etapas de desenvolvimento, contribuindo para uma jornada mais estruturada de evolução do negócio.

[Acessar Projeto Integrador](./projeto-integrador/)

## Arquitetura da Informação

A organização deste portfólio utiliza princípios de Arquitetura da Informação para facilitar o acesso, a compreensão e a localização dos conteúdos.

### Classificação

Os conteúdos são separados em grandes categorias:

- Unidades Curriculares.
- Projeto Integrador.
- Documentação.
- Recursos visuais e documentos auxiliares.

### Taxonomia

Os conteúdos são organizados de forma hierárquica:

```text
Portfólio Acadêmico
│
├── Unidades Curriculares
│   ├── UC
│   │   ├── Atividades
│   │   ├── Projetos
│   │   ├── Documentação
│   │   └── Evidências
│
├── Projeto Integrador
│   ├── Contextualização
│   ├── Pesquisa
│   ├── Requisitos
│   ├── Arquitetura
│   ├── Desenvolvimento
│   ├── Testes
│   └── Entrega
│
└── Documentação
```

### Metadados

Cada atividade poderá apresentar informações como:

- Unidade Curricular.
- Tipo de atividade.
- Semestre.
- Data.
- Status.
- Tecnologias utilizadas.
- Competências desenvolvidas.
- Relações com outros conteúdos.

### Navegação

Os arquivos `README.md` funcionam como páginas de entrada para cada seção do portfólio.

Links internos permitem a navegação entre:

```text
Portfólio
   ↓
Unidade Curricular
   ↓
Atividade
   ↓
Código, documentação e evidências
```

### Encontrabilidade

A localização dos conteúdos é facilitada por:

- Padronização dos nomes das pastas.
- Organização hierárquica.
- Índice geral.
- Links internos.
- Palavras-chave.
- Metadados.
- Topics do GitHub.

### Relações entre conteúdos

As atividades desenvolvidas nas Unidades Curriculares poderão ser relacionadas ao Projeto Integrador e a outros trabalhos acadêmicos.

Dessa forma, um mesmo conhecimento poderá ser encontrado por diferentes caminhos.

Exemplo:

```text
Gestão da Informação
        │
        ├─────────────┐
        │             ↓
        │        ConectaStart
        │             ↑
Qualidade de Software ┤
        │             │
Inteligência Artificial
```
